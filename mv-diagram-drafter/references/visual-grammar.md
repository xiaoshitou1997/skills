# 图面语法

工程图的画法理论：四层结构，每层回答一个问题，每条可对着图面判定过/不过。适用于本 skill 全部图种的绘制与核验；要素取舍按 [图种与要素清单](diagram-elements.md)，本文只管「画得可读」；实现载体是 layout_gen 的 spec 字段与断言，画法细节见 [SVG 图源与渲染](svg-diagrams.md)。

## 元原则

1. **一图一问**：每张图只回答读者一个问题，为一种读者而画。答不了的问题换一张图，答不完的问题分层缩放（环境 → 系统 → 组件）。图超载不是画得细，是没想清给谁看。
2. **编码即承诺**：图上动用的每个视觉通道——颜色、虚实、粗细、形状、箭头——都是「这个样式有含义」的承诺。动用一个通道就全图一致并进图例；无语义可表达的通道保持沉默。
3. **可判定**：规则必须能对图面检查出过/不过。不存在「好看」标准；存在交叉数、对齐、间距、通道一致性、图例完整度标准。

## 第一层 语义层：画什么

- 元素资格制：图上每个元素必须参与回答该图的问题，不参与的删除；极简图（个位数元素）与全景图同等成立。
- 事实来源制：组件、连接、参数全部来自确认过的资料，缺项标「待确认」，不发明。
- 取舍检测：遮住图题问「这张图回答什么」——答不出即语义层不过关，回炉重切，不调样式。

## 第二层 结构层：怎么摆

- 位置编码结构：层级=行；流程方向=全图单一主轴（上→下或左→右，不回头）；作用域=容器嵌套（大区 ⊃ 站点 ⊃ 域）；全局单点=横贯全宽带或中轴独立节点。
- 对称表等价：结构相同的站点必须严格镜像，同构组件同一水平线；不对称处即声明「这里有差异」。对称是语义，不是装饰。
- 交叉最小化是第一布图目标：实证研究（Purchase；Huang 补充交叉角度效应）中影响读图正确率的第一因素是连线交叉，第二是拐弯。手段按序：分层排序消回边、同源合并总线、多链路错道分流；消不掉的交叉靠第三层颜色×虚实保持可分辨——允许存在，不允许含混。
- 硬边界：线不穿节点、不压文字；拐弯对齐图元边缘；网格与间距节奏全图统一。

## 第三层 表达层：怎么编码

每个视觉通道分配唯一语义职务，一个通道一个职务，一个职务一个通道：

| 通道 | 唯一职务 | spec 载体 |
|---|---|---|
| 形状 | 实体类型 | 节点 `shape`：方框=组件、`db` 圆柱=存储、`cloud` 云=外部网络 |
| 颜色 | 角色/状态 | 行 `style` + `role`（图例名随 spec，不随内置名） |
| 线型 | 关系性质 | `kind`：实线=物理/同步，虚线=逻辑/异步/备援 |
| 线色 | 承载通道 | 链路 `tone` + spec `link-tones` 声明（名称→色） |
| 箭头 | 方向性 | 时序 `dash` 返回/异步；拓扑互备对交叉双通道 |
| 边框虚实 | 存在性 | 节点 `ghost`：虚框=逻辑存在/未激活 |

- 判别性：任何两个不同含义的编码，去掉颜色也要能区分（黑白打印、色弱读者过关）。
- 语义透明：形状暗示含义（圆柱像数据库）；领域既定记法优先（Cisco/AWS 图标体系、UML）。
- 图形经济：通道数量与语义区分数量相等——3 种关系用 3 种线型，不用 7 种。
- 双编码：关键编码同时有文字兜底（链路标签、角色标注），不赌读者看懂颜色。

## 第四层 交接层：读者怎么进来

- 图题=答案预告：一句话说清这张图回答什么，正式交付带编号。
- 图例=承诺清单：图中动用过的每个通道必须有一条图例，未动用的通道不进图例；图例条目数=实际编码数，可机器校验。
- 标签语法：节点=名词（术语与资料逐字一致），链路=关系短语；标签垫片不压线不压字。
- 密度上限：一图节点数以一眼数得清为限，超限升缩放层级，不缩字号。
- 留白=分组：空白是免费容器，间距节奏表达亲疏。

## 落地机制

结构层由确定性算法机械化（layout_gen：行模型=位置编码、错道/总线/交叉对=交叉治理、穿箱断言=硬边界）；表达层与交接层由 spec 声明加机器校验兜底（tone 未声明即失败、图例按实际用量生成）；渲染后目检按第四层清单逐项核对。

## 依据

- Purchase, Validating Graph Drawing Aesthetics：交叉与拐弯对理解影响的实证排序。
- Huang et al., Larger crossing angles make graphs easier to read：交叉角度效应。
- Moody, The "Physics" of Notations：判别性、语义透明、图形经济、双编码等记法设计原则。
- c4model.com Notation：每图必带图例、缩放分层、一图一受众。
- Cisco Network Topology Icons / AWS Architecture Icons：领域既定记法优先的范本。
