# 原创性红线

本文定义 mv-ui-style 产出的原创性判定：什么算照抄、什么算合规借鉴、自查怎么记录。推导步骤见 [color-derivation.md](color-derivation.md)，落盘模板见 [design-tokens.md](design-tokens.md)；与 SKILL.md 冲突时以 SKILL.md 为准。

原则依据：设计方法论与公开标准（模数比、对比度公式、栅格、缓动公式、CRAP 四原则）不受版权保护，可引用；具体视觉表达——配色组合、字形授权、图标与插画资产、标志性形制——受版权或商标保护，须自产或取得授权。

## 照抄判定三问

产出交付前逐问核对，任一问不过即回炉重推：

1. **并排测试**：把产出与所参照过的产品并排展示，普通用户能否指认「这是某产品的样子」？能指认即不过关。
2. **来源追溯**：每个 token 能否指出推导来源（DNA 条款、气质参数、公开标准）？说不出来源的取值即不过关，删除重推。
3. **授权凭证**：字体、图标、图片资产是否逐项有授权来源记录（tokens 注明）？缺凭证即不过关，换合规资产。

## 红线清单

| 红线 | 判定标准 | 替代做法 |
| --- | --- | --- |
| 复刻品牌配色组合 | 与某产品的主色+辅助色组合（hue、明暗关系、搭配位置）一致到能唤起该品牌联想 | 重选主色 hue 或改配色结构（主辅关系、占比），重跑推导 |
| 模仿标志性组件形制 | 复用某产品独有且可辨识的控件形态（特定开关造型、特定徽标形状等） | 按家族 DNA 的圆角、描边、图标规则重画形制 |
| 像素级布局仿制 | 布局、间距、层级与某产品逐像素对得上 | 按家族密度档与 4px 栅格重新排版 |
| 视觉资产搬运 | 截图、抠图、反编译取出的字体或图标进入产出 | 自绘，或取 OFL/MIT/ISC/CC0 授权资产并在 tokens 注明来源与授权 |

## 允许的借鉴路径

- **引用公开标准**：4px 栅格、1.25 模数比、WCAG 对比度、公开缓动公式表、CRAP 四原则（对比、重复、对齐、亲密性）——注明标准名即可，标准本身无版权。
- **引用交互模式**：列表-详情、双栏文件管理、标签页等交互概念不受版权保护；实现按家族 DNA 的视觉规则自行表达。
- **自推组合**：hue、密度、圆角、字阶的组合由家族建档推导产生，家族组合本身即原创点；三轴（配色结构、形制、布局密度）至少两轴与任一所参照产品可区分。

## 自查记录格式

交付说明中按三问各记一句结论，例：「并排测试：与 Xshell、Tabby 并排不可指认同源；来源追溯：全部 token 出自 color-derivation 步骤 1–6 与 DNA 表；授权凭证：系统字体栈，图标为自绘 SVG。」

边界：本参考管视觉产出的原创性判定，不构成法律意见；商用授权存疑的资产交法务或权利人确认后再用。
