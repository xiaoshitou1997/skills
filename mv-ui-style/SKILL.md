# UI 风格设计语言

面向自研应用（桌面 Electron、Web、移动端）的界面视觉风格：全家族维护一套设计 tokens，结构 DNA 与配色一并固定，所有应用共用，对齐大厂产品矩阵的公司级设计系统做法（TDesign、Ant Design、Arco 均为公司级全家统一）。管家族风格的建档、套用与一致性评审，不管前端编码实现，不管工程制图。

`读家族 tokens（缺失先建档）→ 套用到应用 → 校验对比度 → 红线自查`

- 运行时落点：家族 tokens master 存 `~/.mv/ui-style/`（环境变量 `MV_UI_STYLE_HOME` 覆盖，供测试与隔离）；应用侧只放引用或注明来源的副本，不另建第二套 tokens。

## 作用与优先级

这是**规范型 Skill**，承载家族设计 tokens。优先级：用户明确需求 → 本设计语言 → 生态默认。需求与家族 tokens 冲突时按「输出与边界」节记录偏离，不静默偏离；应用私改配色或换字体不是偏离通道，统一走家族修订。

核心立场：**引用标准，不引用成品**——方法论取自公开标准（模数比、WCAG 对比度定义、公开缓动公式），具体视觉产出（配色组合、字阶配值、组件形制组合）由家族建档推导产生，不复刻任何现有产品的可识别外观。

## 家族 tokens（全家族唯一一套）

家族参数一次性定档，此后全家族复用；修订家族风格=修订 master 并同步各应用，不存在按应用单独配色。风格锚=苹果平台设计语言（2026-10-24 重申高度对齐）：结构项（字体栈、圆角、动效、材质、焦点态）逐项对照苹果官方语言取 CSS 可落地等价，配色仍走本家族 OKLCH 推导并受原创性红线约束，不取苹果现成色值（accent 与苹果蓝保持 hue/彩度偏移的原创边界，依据见 [references/color-derivation.md](references/color-derivation.md)）。下表为定档结果：

| 层 | 家族值 | 依据 |
| --- | --- | --- |
| 主色 | 蓝域 hue 264（2026-10-24 复刻修订定档），具体色值由推导产生 | 复刻用户原工具蓝（OmniShell v0.1.0 #2F6BFF，git 4863325 确证）；推导衍生不取任何大厂现成色 |
| 档位 | 标准档：色阶骨架 C 0.13，accent 主档 L 0.58/C 0.2294（2026-10-24 accent 复刻修订）；灰调/深调档保留为修订候选 | 复刻用户原工具蓝 #2F6BFF（反推 oklch(0.5806 0.2289 263.9)，取整参数正推逐位还原），白字 4.51；与苹果 systemBlue（oklch(0.603 0.218 257.4)）hue 差 6.6°、彩度偏移，保持原创边界；档位定义见 [references/color-derivation.md](references/color-derivation.md) |
| 间距 | 4px 基数，取值 4/8/12/16/24/32/48，表外值不用 | 4pt 网格为主流设计体系公约数，整除对齐可复检 |
| 字号 | 12/14/16/20/24/30 六档，中文界面正文取 14、辅助取 12 | 中文界面正文可读性惯例，档间比约 1.25 |
| 行高 | 正文 1.6，标题 1.3 | 中文正文行高 1.5–1.7 惯例 |
| 字重 | 400/500/700 三档 | 档位受限，层级靠字阶与字重组合表达 |
| 字体 | 系统栈（苹果优先）`-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Microsoft YaHei", "Noto Sans CJK SC", sans-serif`（2026-10-23 苹果风定档）；展示字体可另选 OFL 授权字体并在 tokens 注明授权 | 系统栈授权零风险、零加载成本；苹果设备原生 SF 渲染，其余平台回退系统字体 |
| 圆角 | 三档语义固定：输入框与标签=8、按钮与卡片=14、弹窗与面板=20（2026-10-23 苹果风定档圆润档；备选标准 4/8/16、锐利 2/4/8） | 相对体系固定，绝对档位建档定死；苹果风连续圆角方向，web 以加大圆角近似 |
| 动效 | 140ms 微交互 / 240ms 常规过渡 / 400ms 面板与页面级；缓动统一 `cubic-bezier(0.32, 0.72, 0, 1)`（2026-10-23 苹果风定档）；必须响应 `prefers-reduced-motion` | 苹果动效以弹簧物理为主（WWDC23），CSS 以其惯用转场曲线近似，时长取 100–500ms 带中段；无障碍要求不变 |
| 材质 | 头部/侧栏等覆盖层可用毛玻璃：`--ui-material-blur: saturate(180%) blur(20px)` + α 0.72 半透明 surface；正文面板不用（2026-10-23 苹果风定档） | 苹果 HIG 材质语言；web 以 backdrop-filter 落地，弱性能环境降级为不透明 |
| 焦点态 | 2px 焦点环 + 2px 外扩，颜色取强调色，与底对比 ≥3:1；不删除 `outline`，以自定义焦点环样式替换默认外观 | WCAG 2.2 焦点可见性要求 |
| 图标 | 24px 栅格、1.5px 描边、圆头端点、单色随文字色 | 与主流 2px 描边图标集（Lucide、Feather、Tabler）形制区分 |
| 语义色 | success=绿系、warning=琥珀系、danger=红系、info=蓝系，hue 区间全家族固定 | 通用语义惯例 |
| 暗色 | 与亮色同一份 hue 推导，映射规则见 [references/color-derivation.md](references/color-derivation.md)；不做脱离推导的独立暗色皮肤 | 同源推导才保持同族 |

## 家族建档（一次性）

首次建立或家族风格修订时执行；日常新应用接入不重复建档：

1. 家族参数已全部定档（2026-10-23 苹果风：色阶骨架 C 0.13、圆润圆角 8/14/20、苹果动效 140/240/400ms、毛玻璃材质、密度标准；2026-10-24 accent 复刻修订：主色 hue 264、accent L 0.58/C 0.2294＝用户原工具蓝 #2F6BFF、按钮白字门槛 3.0），建档直接取用，不代选不重议；家族修订时才重新确认变更项。
2. 按 [references/color-derivation.md](references/color-derivation.md) 从家族参数推导全套颜色。
3. 按 [references/design-tokens.md](references/design-tokens.md) 模板落 master tokens 到 `~/.mv/ui-style/tokens.css`，头部注释记录定档日期与家族参数。
4. 跑对比度校验并按「不可违反的原则」自查，结论记入交付说明。

## 工作流

新应用接入：

1. 取 master tokens（`~/.mv/ui-style/tokens.css`；设置了 `MV_UI_STYLE_HOME` 时从覆盖目录取）；master 不存在时先走「家族建档」。
2. 引入应用项目：复制为项目内 tokens 文件并在头部注释注明 master 来源与同步日期，或按项目构建方式直接引用；不修改家族值，新风格诉求走家族修订。
3. 运行对比度校验（命令见下）。
4. 对照「不可违反的原则」自查，结论记入交付说明。

对比度校验：

```bash
SKILL_ROOT="/实际绝对路径/mv-ui-style"
python3 "${SKILL_ROOT}/scripts/check_contrast.py" <前景> <背景> [<前景> <背景> ...]
```

`SKILL_ROOT` 必须显式设为本次加载的 skill 目录，不能假设环境已提供；脚本路径恒加引号；命令从用户项目目录执行，不在 skill 目录内产生文件。文字对按默认阈值 4.5 校验，纯 UI 部件对（边框、焦点环）可用 `--min 3`；退出码非零时按 [references/color-derivation.md](references/color-derivation.md) 的回改规则重跑。

风格一致性评审：

1. 对照 master tokens 逐项核对应用实际取值：颜色、圆角、动效、焦点态。
2. 色阶外散落取色、表外间距与字号逐处列出。
3. 产出问题清单，每条给出回到 master 的具体改法（改哪个 token、取哪一档值）；应用侧无法解决的问题记为家族修订建议，不在应用内私改。

## 不可违反的原则

- **一套 tokens**：全家族只存在 master 一份家族 tokens；应用不另建配色体系、不改主色、不引入第二套字体栈。新风格诉求走家族修订，不在应用内私改。
- **不复刻可识别外观**：禁止像素级仿制布局、复用现有产品的品牌色组合、模仿标志性组件形制。判定标准：把产出与任一现有产品并排，普通用户能指认「这是某产品的样子」即不过关，按 [references/originality-rules.md](references/originality-rules.md) 回炉重推。
- **产出可追溯**：每个 token 能指出推导来源（家族 tokens 条款或建档推导记录）；说不出来源的取值删除重推。
- **资产授权干净**：字体只用系统栈或 OFL 授权字体；图标自绘或用 OFL/MIT/ISC 等宽松授权图标集并在 tokens 注明来源与授权；图片素材取可商用授权；禁止截取或抠用他人产品的视觉资产。
- 冲突时按用户明确需求 → 本设计语言 → 生态默认处理。

## 输出与边界

建档产出 master tokens 文件（头部含定档记录）与自查结论；应用接入产出注明来源的 tokens 副本或引用与自查结论；评审产出问题清单与逐条改法。偏离家族 tokens 的项在应用 tokens 头注释逐条记录理由并列为家族修订候选，未记录理由的偏离按不合规处理。工程图与页面示意图的绘制归 mv-diagram-drafter；前端框架与技术栈选型归 mv-tech-stack-standards；组件代码结构与前端编码规范不在本 skill 范围。
