# 数据分级与保护

配合 mv-security-standards 使用。数据分级由项目按行业合规与业务事实确定；本文件给默认分级与工程控制，不替代法务/合规结论。

## 分级

| 级别 | 示例 | 默认控制 |
| --- | --- | --- |
| 公开 | 产品介绍、公开文档 | 完整性校验 |
| 内部 | 内部配置、非敏感运营数据 | 登录后可访问；不公开索引 |
| 敏感 | 手机号、证件号、地址、订单明细、员工信息 | 最小采集；展示脱敏；传输加密；日志禁打；按角色授权 |
| 高敏 | 密码/密钥、支付凭证、健康/生物识别、未成年人信息 | 强加密存储；单独授权与审计；最小留存；禁止进入测试数据 |

分级结果写入项目数据清单：字段、级别、采集目的、留存期、访问角色、脱敏方式、删除方式。

## 工程控制

- **最小化**：只采集业务必需字段；能用聚合值不用明细；能用匿名标识不用真实身份。
- **展示脱敏**：列表与详情按角色返回脱敏值；完整值经单独权限与审计；导出同样脱敏。
- **传输与存储**：外部链路 TLS；高敏字段应用层加密或字段级加密；密钥与数据分离存放。
- **日志**：不记录密码、令牌、完整证件号、完整银行卡、完整请求体；错误信息不回显敏感值。
- **测试数据**：生产数据不直接进测试；需要时脱敏或造数；测试环境使用独立凭据。
- **留存与删除**：按合规与业务定留存期；到期删除或匿名化；删除覆盖备份与派生数据，写明备份保留窗口。
- **租户隔离**：共享表模型所有查询强制租户条件；导出、报表、后台任务按租户隔离；跨租户操作单独授权并审计。

## 边界

认证授权实现、前端展示与输入处理归 mv-coding-standards；备份与恢复归 mv-ops-standards；合规结论由项目与法务确认。
