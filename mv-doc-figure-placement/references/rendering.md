# 文档侧图嵌入与核验

适用于已有图源或成品图片放入文档之前的嵌入形式判定与图片核验。图源画法与本地渲染命令归 mv-diagram-drafter；用户要求的格式和项目现有约定优先；本文不决定文档正文内容。

## 嵌入形式判定

| 情形 | 处理 |
| --- | --- |
| Markdown 阅读器支持 Mermaid | 可直接嵌入 `.mmd` 源码块，图源随文档保留 |
| Markdown 不支持或需要稳定显示 | 引用 `fig-out/` 已渲染 PNG |
| Word/PPT | 一律使用已渲染 PNG，渲染由 mv-diagram-drafter 的绘制流程完成 |

文本图源保存在文档项目的 `fig-src/`，图像保存在 `fig-out/`，命名对应，例如 `fig-src/login-sequence.mmd` → `fig-out/login-sequence.png`；文档有多个版本时使图片和源文件随版本一起更新。

## 图片核验

插入前检查 PNG：可打开、文字清晰、背景对比满足目标文档、整体未裁切且宽高比正常；渲染方式与倍率由绘制流程记录，本 skill 核验成品并记录结果。已有页面截图核对来源、页面状态与取图时间并随文档记录；不将仅有 PNG 的图称为可编辑图源。

## 边界

本文只负责文档侧的嵌入判定与图片核验；图源画法、渲染命令与浏览器发现见 mv-diagram-drafter，文件插入与替换操作见 [Office 配图指南](office-figures.md)。
